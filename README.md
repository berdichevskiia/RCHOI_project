# YouthBank — Demo Ready Project

Это готовая демо-версия многостраничного React-приложения «YouthBank» для молодёжи и предпринимателей.

## Содержание архива
- `public/index.html` — точка входа
- `src/index.jsx`, `src/App.jsx` — приложение React (React Router)
- `src/styles.css` — стили (цвета, типографика, доступность)
- `package.json` — упрощённый пакет для локального запуска (Parcel)
- `DEMO-CREDENTIALS.txt` — демонстрационный логин/пароль

## Как запустить (локально)
1. Установите Node.js (рекомендуется 18+).
2. В корне проекта выполните:
   ```
   npm install
   npm run start
   ```
3. Откроется dev-сервер, обычно на `http://localhost:1234`.

> Это демо-версия UI. Backend-авторизация, загрузка паспортов и интеграции с бухсофт не реализованы — в приложении они показаны как заглушки/макеты.

## Сценарии, покрытые в приложении
- Открытие счёта студентом (Анна) — регистрация, виртуальная карта, цель накопления.
- Работа самозанятого (Илья) — создание чека, отправка клиенту, выписка.
- Открытие расчётного счёта для ООО (Мария) — загрузка документов, мультидоступ, интеграция.
